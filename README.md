# QuizNow —— Obsidian 快速考试与复习插件

一个简洁、现代、轻量的 Obsidian 插件：**基于当前笔记快速生成考试试题**，支持
**单选 / 多选 / 填空 / 判断**四种题型，采用 **SM-2 间隔复习**算法管理错题与薄弱点，
帮助你在 Obsidian 里完成"学习 → 考试 → 复习 → 巩固"的闭环。

> 纯原生 DOM 实现，无任何运行时框架，资源占用极低。
> 界面支持 **简体中文 / English / 日本語 / 한국어** 四种语言，可在设置中切换。

## 功能一览

| 板块 | 内容 |
| --- | --- |
| 🏠 首页 | 第一栏：试题数量 / 错题数量 / 待复习数量 / 试卷数量统计卡；第二栏：每份试卷的**最高分**卡片（展示数量可在设置中调整） |
| 📝 考试 | 闪卡式答题；单选/判断**点击即自动提交**，多选/填空手动提交；四种题型；题目数量自由设定；生成后可选「立即答题」或「加入题库」；答错的题自动存入题库数据库并进入复习队列 |
| 🔄 复习 | 考试答错的题自动汇总；按 SM-2 间隔复习重新答题；**再次答错自动移入薄弱点** |
| 🎯 薄弱点 | 反复答错、未真正理解的知识点；可**生成解释**（AI 或自动提取笔记上下文）帮助记忆；按 SM-2 对薄弱点出题重新作答 |
| ⚙️ 设置 | 题库数据库路径、默认出题数量、评分方式、题型组合、首页成绩卡数量、SM-2 参数、薄弱点掌握阈值、AI 接口、**自定义生成指令**、**界面语言**、**数据备份/恢复**等全局配置 |

## 快速开始

1. 下载本仓库，把 `main.js`、`manifest.json`、`styles.css` 放到
   `<你的库>/.obsidian/plugins/obsidian-quiznow/` 目录（若无则自建）；
2. 在 Obsidian「设置 → 第三方插件」中启用 **QuizNow 快速考试与复习**；
3. 点击左侧边栏的 🎓 图标，或命令面板执行 `QuizNow：打开主面板`
   （主面板在**主内容区的新标签页**中打开，不使用侧栏）。

首次启动会自动创建示例题库数据库 `QuizNow/题库.json`（3 道示例题），
可在 Obsidian 中直接查看、修改或删除。

## 典型使用流程

1. **从笔记出题**：打开一篇笔记（重点术语用 `**加粗**` 标记，或"键: 值"形式），
   点击文档标题栏右上角的 📋 按钮，或执行命令 `QuizNow：基于当前笔记生成试题`，
   生成过程中会有提示，完成后在弹出的预览窗口选择：
   - **立即答题** → 直接开始考试；
   - **加入题库** → 全部题目写入题库数据库 `QuizNow/题库.json`。
2. **考试**：在「考试」标签设置题目数量与题型，从题库/薄弱点抽题作答；
   交卷后记录分数，答错的题自动加入题库与复习队列。
3. **复习**：到期的错题按 SM-2 闪卡复习，自评记忆质量（忘记/困难/良好/简单）；
   再次答错 → 自动移入「薄弱点」。
4. **薄弱点**：点击「✨ 生成解释」（配置 AI 后为 AI 讲解，否则自动提取笔记上下文），
   然后通过「薄弱点测试」重新答题，连续答对（默认 2 次）即视为掌握并移出。

## 命令与快捷键

| 命令 | 说明 |
| --- | --- |
| `QuizNow：打开主面板` | 打开插件主界面 |
| `QuizNow：快速考试（题库随机抽题）` | 一键开始一场随机考试 |
| `QuizNow：基于当前笔记生成试题` | 根据当前打开的笔记生成试题 |

## 题库存储（单文件数据库）

题库保存在**单个 JSON 数据库文件**中（默认 `QuizNow/题库.json`，可在设置中修改路径），
所有题目集中存储，不会产生大量细碎的 Markdown 文件，随库同步、易于备份。

数据库文件结构：

```json
{
  "version": 1,
  "questions": [
    {
      "id": "唯一id",
      "type": "single | multiple | fill | judge",
      "content": "法国的首都是哪里？",
      "options": ["伦敦", "巴黎", "柏林", "罗马"],
      "answer": ["B"],
      "explanation": "巴黎是法国的首都",
      "source": "我的笔记",
      "createdAt": 1720000000000
    }
  ]
}
```

> 从旧版本升级时，原 `QuizNow/题库/` 文件夹中的 Markdown 题目文件会自动迁移
> 进数据库文件（原文件夹保留，可手动删除）。

## 数据备份

在「设置 → 数据备份」中：

- **立即备份**：把题库、考试记录、SM-2 记忆进度与全部设置导出为一个
  `quiznow-backup-时间戳.json` 文件（默认存放于 `QuizNow/backups/`）；
- **恢复**：从备份列表中任选一份恢复（恢复前会自动先备份当前数据，防止误操作丢失）；
- 备份文件可随时复制到其它设备，恢复后完整还原插件状态。

## AI 生成（可选）

在「设置」中填写 OpenAI 兼容接口（如 OpenAI / DeepSeek / 通义 / 本地 Ollama 等）：

- **API 地址**：`https://api.openai.com/v1`（或其兼容地址）
- **API 密钥**、**模型**、**每次生成数量**
- 勾选「启用 AI 生成试题与解释」后：
  - 「基于当前笔记生成试题」将调用 AI 出题（失败自动回退内置生成）；
  - 「薄弱点」的「生成解释」将调用 AI 通俗讲解。

**自定义生成指令**：在「设置 → 自定义生成指令」中可以新增 / 删除多条自定义
AI 指令（prompt），并选择当前使用哪一条；不选择时使用内置的
多语言系统默认指令。指令文本中可使用 `{count}`（生成数量）与 `{types}`
（启用的题型）两个占位符。

未配置 AI 时，插件使用零成本的内置启发式生成（加粗术语 → 填空/单选，键值对 → 填空）。

## 多语言

在「设置 → 界面语言」中选择 **简体中文 / English / 日本語 / 한국어**，
保存后整个插件界面（含命令名、提示、通知、AI 默认指令）即切换语言。

## 开发

```bash
npm install
npm run dev        # 监听模式，输出 main.js
npm run build      # 类型检查 + 生产构建
```

- `src/types.ts` — 数据模型与设置项
- `src/question.ts` — 题目 Markdown 格式解析 / 序列化 / 答案判定
- `src/generator.ts` — 内置启发式出题与解释提取
- `src/ai.ts` — OpenAI 兼容 AI 客户端
- `src/sm2.ts` — SM-2 间隔复习算法
- `src/store.ts` — 数据持久化、题库数据库（单文件 JSON）与备份/恢复
- `src/views/` — 首页 / 考试 / 复习 / 薄弱点 / 设置五个视图

## 说明

- 试卷最高分按试卷名记录：同一试卷名重考只保留最高分；不填试卷名时自动以
  "来源 · 时间" 命名，即为新试卷。
- 所有数据保存在插件 `data.json` 与题库数据库文件（`QuizNow/题库.json`）中；
  卸载插件不影响数据，重装后自动读取。
